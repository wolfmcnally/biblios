The Starter stamp carried a kickoff-config whose preflight could qualify a Codex reviewer only by spawning the codex CLI, while the operator's coordinator required Folded launcher-managed reviewer sessions. A multi-store consumer's checkout held the route as an uncommitted local extension (--folded-probe), so it had to be ported by hand into the new project before kickoff could start. Promote the Folded probe branch, its test and README paragraph into the template so a stamp ships with it.
